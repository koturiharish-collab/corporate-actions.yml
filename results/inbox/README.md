# Share Sanket - Results Inbox

This folder stores verified company financial result announcements.

## Accepted source
- NSE official announcements
- BSE official announcements

## Required fields
- symbol
- company
- period
- published_at
- source
- source_url

## Optional financial fields
- revenue
- net_profit
- eps
- operating_profit
- gross_profit
- ebitda
- total_debt
- cash_flow

## Important
- Do not enter estimated or invented financial figures.
- Include the official announcement URL.
- Use NSE or BSE as the source.
- Analyst estimates require a separate verifiable source.
